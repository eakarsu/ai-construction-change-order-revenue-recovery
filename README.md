# Construction Change-Order Revenue Recovery

A domain-specific React, Express, PostgreSQL, and OpenRouter system that turns field evidence and contract entitlement into approved, billed, and collected change-order revenue.

- 12 construction revenue capabilities and 48 custom domain fields.
- Three scenario-fill buttons per capability.
- 15 PostgreSQL records per capability (180 total).
- Cost reconstruction, schedule impact, pay-application reconciliation, recovery analytics, governed states, and audit history.
- Professional structured AI decision briefs without raw JSON rendering.

Run `./start.sh`, then open <http://127.0.0.1:4532>. The API runs on `5532`.
